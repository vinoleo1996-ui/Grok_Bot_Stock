## 0. 诚实范围（方案 §0–§1，照录约束）
- Gerko/XTX 是 AI **做市与短周期预测**，不是日频选股工厂；我们不声称复刻 XTX。
- 数据：日频面板（非 Tick/盘口）；算力：约 8 核 / 15GB、无 GPU 集群 → 禁大模型、禁无约束超大 GP。
- L1 = 算子库 + 遗传规划/符号回归（主）+ 小模型表示学习（辅）+ LGBM/Elastic Net 基线；L3 做市级明确放弃。
- 硬目标语境：扣成本 12%–15%、MDD≤25%、**禁小盘主线**、**拒高杠杆凑数**（挖因子主线不加杠杆；>1.5× 禁止）。
- AI 袖套预期贡献约 +3～+8pp（方案 §2.6），不单独裸奔扛 12%；若密封证明纯 AI long-only 达标再升格。

## 1. 宇宙与容量（方案 §2.1 / §2.4， verbatim）
- 流通市值前 1500，或沪深300/中证500 历史成分；**禁止小盘主线**（小盘只作 `CONTROL_ONLY` 对照）。
- **容量：** 单票 ≤ 组合净值 × 上限；日均成交额下限；总持仓 ≤50（与 AGENTS 一致时服从用户上限）。
- **杠杆：** 挖因子主线 **不加杠杆**。
- **成本：** 默认单边 ≥10–25bp（与现有引擎一致）；**换手进适应度**（不是事后才扣）。

## 2. 管线顺序（方案 §2.1，不许跳步）
```
原始面板 (PIT)
  → 特征库 / 算子库（可审计）
  → AI 生成候选因子（GP / 符号回归 / NN 表示）
  → 探索窗筛选（2024-06 起；或训练窗但禁止偷看密封标签）
  → 多重检验与容量/成本闸门
  → 预注册 → 密封窗单次（2018-01～2024-05）
  → 通过则进组合账本 + 前向模拟盘（2026-11 起）
```

## 4. 算子库范围（方案 §2.2；实现：`quantlab/factors/ops.py`）
原子算子（全部 PIT / asof）：
- 价格/量：`ret(n)`, `log_price`, `amihud`, `turnover`, `vol(n)`, `skew`, `max_ret`, `gap`, `limit_up/down` 状态
- 截面：`rank`, `zscore`, `industry_neutral`, `size_neutral`（中性化是**可选臂**，非默认）
- 基本面 / 资金 / 事件 / 宏观：按数据就绪逐步接入；未就绪不算子进搜索
禁止：未来收益进特征；复权用错；成分用期末名单；财务用报告期而非公告日。

复杂度：树深度与节点数上限写入搜索配置；**表达式复杂度惩罚进适应度**。

## 5. 适应度（成本与容量进函数，方案 §2.3 B1）
最大化探索/训练协议允许窗口内、**中大盘**、市值加权视角下的 IC 或 long-only excess / top-bottom，同时减去：
- 换手惩罚、单票权重上限违约惩罚、行业集中度上限惩罚
- 可选：对市值/行业暴露惩罚（或强制报告暴露）
- 复杂度惩罚  
输出：**Top-K 表达式** + 自然语言释义 + 失效假设（谁在付钱）——本周 KPI（方案 §3.6 / §4.4）。

## 7. 多重检验与账本（方案 §2.4 / §3.2 E2）
- 每个候选**计次**；报告探索尝试次数 N；写入 `output/ai_factor/ledger.jsonl`（字段：`attempt_id, N, seed, universe, cost, window, engine, expr_hash`）。

## 9. Kill lines / 失效（方案 §4 + §2.4）
任一即失败并停晋级：
- 无计次或触碰密封标签；
- 扣成本后密封（或探索闸门）净收益 ≤0 / 相对 510300 超额不达预注册阈值；
- 挖出因子与 size/liquidity 相关过高（方案：若 80% 相关于 size/liquidity → 判失败）；
- GP 不能稳定打赢 LGBM 扣成本 long-only（§2.3 B3）；
- 无机制注释（钱从谁来）的表达式不得进密封；
- 用小盘或 >1.5× 杠杆补丁。
