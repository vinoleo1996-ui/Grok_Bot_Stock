## 1. 股票池
- U1（主）：信号日 t 收盘，可交易（tradestatus=1）、非 ST、上市 ≥120 交易日、有收盘价，按 t 日流通市值（float_mktcap_daily_tushare，PIT）取前 1500。
- U2（交叉检验）：沪深300+中证500，用 index_weight_csi300_500_1000.parquet 中 ≤t 的最近月末快照成分（月度快照，月内调样有最多约 1 个月滞后，记为局限）。
- 买入可行：t+1 开盘非停牌、非开盘涨停，否则该名不买入（保留现金）。

## 2. 特征（全部 t 收盘可得，截面秩变换到 [-0.5,0.5]，缺失填 0）
R02_20D(−20日收益)、turn_20d(−20日均换手)、L01_RV60(−60日波动)、V02_BP(1/pb)、EP(ep_pit，按 available_at)、Amihud（符号修正：非流动性为正，×1e9）、MOM_12_1、log 流通市值、SW L1 行业哑变量（PIT）、LHB20（近 20 日上龙虎榜）、LU5（近 5 日收盘涨停）。

## 3. 目标
y_net(H) = 开盘(t+1)→开盘(t+1+H) 复权收益 − ĉ_i，ĉ_i = 往返估算成本 = 2×2.5bp 佣金 + 当日卖出印花税（2023-08-28 前 10bp、后 5bp）+ 2×1.0×σ_d,i×√(V/ADV20_i)，V = 5e7/N。H ∈ {5, 20}。

## 4. 模型（不调参）
- Ridge，λ=10（特征已秩变换），用 numpy 闭式解。
- 树模型：箱内 python3 无 lightgbm / sklearn / scipy，不安装（共享机内存紧），**本轮不跑树模型**，记为偏离计划。
- 训练：在密封窗内 expanding walk-forward，每年 1 月初重训一次；训练样本 = 自 2018-01-02 起、标签在重训日前已到期的全部采样日（禁区 H+1 交易日）。首个测试年 2019（2018 仅作训练）。
- 采样：每 5 个交易日一个信号日（H=5 不重叠）；H=20 每 20 个交易日调仓。

## 5. 组合
等权多头 top-N，N=100。换手惩罚：未持有名的排序分 = 预测值 − ĉ_i（已持有不扣）；持有缓冲：已持有名若调整后排名 ≤150 则保留，空位按调整后分数补满。
