## 1. 机制（谁把钱给我们）
解禁后的原始股东（PE/VC、首发前股东、定增认购方）受基金存续期、LP 分配、质押与持股成本约束，**必须在解禁后的窗口内减持，且对价格不敏感**；对手方（承接的二级市场多头）需要折价才肯接货。可预见的供给冲击在 A 股因融券稀缺无法被事前充分套利（做空方受限），价格只能在解禁前后被动压低。只做多约束下，我们的收入 = 在中大盘持仓里**提前回避**大额解禁股、解禁后低吸，从「被动持有并承接卖压」的指数/主动多头那里拿走这部分折价。与 P8（公告事件）区分：A3 只用解禁日程（事前数月可知的确定性供给），不依赖公告文本分类。

## 3. 信号与股票池
- 股票池：每月末快照的沪深300∪中证500（快照日 < 调仓日），剔除停牌、ST、开盘涨跌停不可交易。
- 解禁强度 S = 未来 [t+1, t+20] 交易日内可见解禁股数 × t−1 收盘价 / t−1 流通市值（即解禁市值/流通市值）。
- 「大额」：S ≥ 5%（固定阈值，不调）。

## 4. 试验（族 = 本表 ≤4 臂；BY 校正只在本族内）
基座 BASE：300∪500 等权，月度首个交易日开盘调仓（与 V3-A1 基座同口径，扩到 500）。
- A3_T1_AVOID20：调仓时剔除 S≥5% 的股票（资金等权分给其余）。
- A3_T2_AVOID20_REENTRY：同 T1，但解禁日后第 20 个交易日开盘允许重新买回（中途调仓）。
- A3_T3_SCALED：权重 ∝ 1/(1+10·S)，归一化（无阈值，作剂量-反应检验）。
- A3_T4_PLACEBO：用 float_date 整体平移 −250 交易日的伪日程做 T1（安慰剂，预期增量≈0；若显著则判机制不成立）。
