## 0. 价格与状态口径
- 收益：复权价（价格×factor）。限价判断：未复权 close/high/low 对 limit_up/limit_down，容差 0.005 元（与探索脚本一致）。
- 封板(t)：close ≥ limit_up−0.005；炸板(t)：high ≥ limit_up−0.005 且未封板；跌停封死(t)：close ≤ limit_down+0.005；撬板：low ≤ limit_down+0.005 且未跌停封死。
- 状态于 t 日 15:00 后已知（PIT），只能用于 t+1 及以后的交易。

「510300 成分等权持有」= 沪深300 成分等权。成分取 index_weight_csi300_500_1000.parquet 中 trade_date < 调仓日 的最近月末快照（月度快照，月内调样最多约 1 个月滞后，记为局限）。

## 3. 试验（多重检验族，A1 共 4 个；与 A2 已预注册臂合并做 BY，A2 若 blocked 则不计入实际检验数并注明）
- A1_T1 SELL_SEAL：持有名 t 日封板 → t+1 开盘卖出（可卖时），t+2 开盘起用该笔卖出所得回补（不可买则次日重试；遇月度调仓则并入调仓）。
- A1_T2 NOBUY_COOLDOWN：t 日炸板或跌停封死 → 该名在 t+1…t+3 三个交易日内禁止新买入（月度调仓与回补均适用；被禁名份额在其它可买名间等权分配）。§4 中「t 日尾盘卖出」需分钟/尾盘数据 → **阻塞，不做**（用收盘价成交属于前视）。
- A1_T3 BUY_VWAP：所有买入改在当日以 VWAP 近似价成交，VWAP≈(O+H+L+C)/4（复权）；卖出仍在开盘。没有分钟数据，近似误差记为局限；买入日开盘→VWAP 之间资金为现金。
- A1_T4 ALL：T1+T2+T3 同时启用（T1 的回补也用 VWAP 并受 T2 冷却约束）。
- 不做：炸板次日开盘买入/隔日卖出（§5 仅 +18bp、t=1.3，§8 未列入）。

## 4. 成本（每臂与基础持仓同口径分别计算）
- flat：单边 25 / 50 / 100bp × 成交额（不另加佣金印花）。
- impact：佣金 2.5bp（最低 5 元）+ 卖出印花（2023-08-28 前 10bp，后 5bp）+ 平方根冲击 tv×k×σ20×√(tv/ADV20)，k=1.0（quantlab.platform.execution.sqrt_impact_cost，即 smallcap_combo_p6 所用口径），σ20 = 前 20 日复权收盘收益标准差，ADV20 = 前 20 日成交额均值（均截至 t−1）；资金 5e7 / 2e8。
