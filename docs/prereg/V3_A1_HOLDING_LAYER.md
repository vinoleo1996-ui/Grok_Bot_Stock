## 1. 机制（持有层，非独立选股）
涨跌停 + T+1 把价格发现推到次日竞价；已持仓方可在封板次日开盘兑现隔夜溢价并躲开日内回落；炸板/跌停封死后禁买，躲开隔夜供给冲击。付钱方：竞价追涨与锁仓恐慌抛售的散户。**不是**独立多空 alpha，是叠在 CSI300 等权底仓上的持有层增量。

## 2. 数据与 PIT
- 面板：`data/local_market/.../panels` 或 asof_extend 等价路径（open/high/low/close/factor/limit_up/limit_down/tradestatus/limit_ratio_at_open）
- 封板：close≥limit_up−0.005；炸板：high≥limit_up−0.005 且未封板；跌停封死：close≤limit_down+0.005
- 状态 t 日 15:00 后可知 → 交易不早于 t+1 开盘
- 成分：沪深300 历史权重月末快照（`index_weight_csi300_500_1000.parquet`）；月内调样滞后记局限
- 中大盘：底仓为 CSI300；状态表诊断宇宙可为流通市值前 1500（与旧口径一致）

## 3. 基础持仓
CSI300 成分等权；每月首个交易日开盘再平衡；可买/可卖规则同旧 A1；开→开净值；现金零收益。

## 4. 试验臂（≤4；BY 在实际运行臂上）
- **HL_T1 SELL_SEAL**：持仓名 t 封板 → t+1 开盘卖出（可卖），t+2 开盘起回补等权（受可买约束）。
- **HL_T2 NOBUY_COOLDOWN**：t 炸板或跌停封死 → 该名 t+1…t+3 禁止新买；份额在其它可买名间等权分配。不做「t 日尾盘卖」（无分钟则阻塞，禁止用收盘价冒充）。
- **HL_T3 CTRL_20PCT**：仅当 `limit_ratio_at_open≥0.19` 时启用与 T1 相同的卖出规则（预测增量弱于 T1）。
