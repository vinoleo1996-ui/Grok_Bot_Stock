## 81% 的核对

这不是净值引擎漏扣佣金后算出来的。`run_book` 使用 `ExecConfig.strategy_v1()`。成交时现金扣佣金、卖出印花税和 `impact_k=1` 的冲击，见 `quantlab/platform/execution.py` 第 778–796 行。`strategy_v1` 没有改 `slippage`，类默认是 0，所以没有另加一笔固定滑点。`summary.json` 只存了净值统计，没有把这三笔费用的金额单独写下。

也不是整段收益被算了两次。信号日用收盘市值决定股数，下一交易日开盘才成交。同一套引擎下，mid-large 的 60 万 CAGR 是 −1.79%，沪深300 是 17.38%。若是全局漏成本或收益对齐错误，这三本账会一起偏高。

持仓规则是 `sorted(pool)[:60]`，见 `research/rd_ablation_20261101.py` 的 `stable_book`。宽篮当天约 2000 只，代码序把 `bj.` 排在 `sh.` 和 `sz.` 前面。按这个规则重放三个决策日：
