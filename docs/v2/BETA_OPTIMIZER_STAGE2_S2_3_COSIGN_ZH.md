## 1. 焦点一：不交易带会不会把 β 推出 ±0.10

### 1.1 推导（最坏情形）
记被冻结（带内保持）的股票集合为 F，δ_i = w_cur,i − w_tgt,i，|δ_i| ≤ b = 0.005。现金 β=0；口径② 中 510300 固定 20%，复核公式里取 β=bb（全池 wb 加权 β），对 β 偏离的贡献恒为 0。

- **由现金吸收（草稿实际情形，Σδ≠0）**：Δβ = Σ_{i∈F} δ_i·β_i，所以 |Δβ| ≤ b·Σ_{i∈F}|β_i|。
  - 20 只、β_max=1.3：≤ 0.005×20×1.3 = **0.130**
  - 30 只、β_max=1.5：≤ 0.005×30×1.5 = **0.225**
  - 两者都大于整个 ±0.10 的 β 框。
- **预算中性（Σδ=0，比如按比例回补）**：Δβ = Σ δ_i(β_i − β̄)，|Δβ| ≤ b·Σ|β_i − β̄|。|β_i−β̄| ≤ 0.5 时，20 只 ≤ **0.050**，30 只 ≤ **0.075**。
- **单票上限交互**：单票上限 5%/6% 不进入 Δβ 上界（δ 已被 b 截住），但会让 w_cur 停在上限之上（见 §3）。
- **结论**：理论上最坏情形会击穿 β 框，所以带后复核**必须**存在，而且必须用带后、整手后的权重（修订版已满足）。

### 1.2 经验核查（非收益；用 pre-ruling 目标只作机制演示，不作 C4 基线）

## 2. 焦点二：510300 豁免是否合理

**合理，同意豁免。** 理由与限定如下：
1. 在实现里，510300 不是自由变量：口径② 固定 20%，β 按 bb 计，对 β 偏离的贡献恒为 0。所以它**不会**吸收 β 残差，也就不存在借它绕过 β 框的后门。豁免的实际含义只是：每次调仓把 510300 拉回 20%。
2. 如果把 510300 纳入带，它会在 20% 附近漂移，口径② 就不再是冻结 PREREG §5 定义的「80/20 同形」，反而破坏与 capacity_adv 总账的可比性。豁免有利于保住可比性。
3. 漂移导致的 510300 回补量很小（模式A 中位 ≈0.4% NAV/次），但必须**单列披露**，不计入股票口径的门槛量（草稿的「只算股票部分」已排除它，Beta 要求写明，即 B4）。
4. 口径①、② 的带都以 NAV 计（0.5%）。口径② 的股票袖只有 80%，所以按股票归一后，带宽相当于股票袖的 0.625%，比口径① 宽。两个口径的带后换手**不可直接比较**，须在披露中注明（B4）。
5. 复核里「510300 β = bb」是建模假设。真实 510300 对 HI_LIQ wb 的 β 不必等于 1，须逐期披露 510300 对 wb 的滚动 β（L_BETA=60），只披露（B4）。
