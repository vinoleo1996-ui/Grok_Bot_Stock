## 3. 预注册允许下的结论（只有这些）
1. **头条**：只能引用 §0 第 3 条的 RAND 中位数 [p10, p90]。
2. **100万 标「对选择规则敏感」；60万 标「头条不稳定」。** 两档的头条都要降级表述。
3. **PROD 是不是靠并列打破的运气？** 预注册没有设检验，只能这样读：
   - PROD 的次级排序来自固化了 PYTHONHASHSEED 的集合迭代顺序，与收益无关，性质上等于又一次任意抽签。
   - 如果 PROD 与 20 个 RAND 可交换，100万 CAGR 落到 21 个里前 3 名的概率是 3/21 ≈ 14%；MDD 落到最深 2 名的概率是 2/21 ≈ 10%。两者都远没到「不可能是运气」的程度。
   - 100万 PROD 是**高收益、深回撤**的一条路径：CAGR 在上尾，MDD 比 19/20 个种子都深，而 Calmar 分位 0.80、Sharpe 分位 0.85 都在分布之内。它不是风险调整后更好，而是暴露更偏向尾部的一次抽签。
   - **允许写**：「现行 N1 规则在 100万 档的 X2 结果位于并列打破分布的上尾（CAGR）和下尾（MDD），与运气无法区分，不能归功于规则。」
   - **不允许写**：「PROD 更好」「PROD 有超额」，或把它的排名当证据。
4. **X2 上，差距小于 RAND 宽度的比较都没有意义。** 60万 p90−p10 = 8.45pp，100万 = 3.83pp。用 B4 与其他方案比较时，差距小于这个宽度的结论不能成立（这是对 B4 A–D 材料的提示，不改任何门槛）。
5. **ADV 和 SPLIT 只作披露（§4-4）。** ADV 两档都落在分布之外的下方，这只能当作一条现象记下：「在并列组内，偏向高 ADV 的选择更差」。不得据此提出「偏向低流动性」的规则，否则就是事后假设。
6. **纸面 B4 永不因本次结果改变（§4-7）。**

## 4. 「改用 CODE」的诱惑：明确禁止
- CODE 在两档的 MDD 都是 21 个里最浅的，Calmar 分位都是 1.0，100万 CAGR 也最高。这正是最容易被拿去「换规则」的结果。
- 不能换的理由：
  1. 预注册 §4-6 明文：CODE、SPLIT、ADV 以及最好的 RAND 种子，一律**不得**因为本次结果被选为新规则（脚本 `SELECTABLE=()`）。
  2. CODE 不是随机抽签，而是按代码字母序。并列组内会系统性地先选 0 / 3 开头的深市股，后选 6 开头的沪市股和 688 科创板。任何「CODE 更好」的解释都是看过结果之后才提出的结构性假设，而且要面对 4 个命名变体 × 2 档 × 多个指标的多重比较。
  3. 预注册 §2 写明，CODE ≈ 已隔离的旧腿和**纸面 B4 的实际效果**（事件腿文件按代码排序）。由此得出一条**必须披露**的推论：纸面 B4 的实际并列效果在 X2 落在分布上尾（MDD 最浅），纸面前瞻的预期应以 RAND 中位数为锚，不能以 CODE 或 PROD 的数字为锚。这条推论**不**构成修改纸面的理由（§4-7）。
- 任何规则修改都必须同时满足：主 Agent 裁定、Leo 决定、走冻结流程、新的预注册，以及**用 2026-11-02 起的 FWD 窗口（X2 之外）检验**。X2 只是入场券，不能用 X2 结果选规则。
- 扩种子（比如到 50）同样禁止：预注册 §2 只允许运行前以精度为理由决定，现在已经看过结果。
