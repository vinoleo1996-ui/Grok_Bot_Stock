# IF 单季度手工对账（engine vs 独立 pandas）

脚本：`scripts/if_quarter_handcheck.py`（`PYTHONPATH=. python scripts/if_quarter_handcheck.py`），逐日明细：`output/v2_proto/if_quarter_handcheck.csv`。

**数据：合成。** box 上 `data/v2/futures/raw/` 为空，CFFEX 官网在 box 上不可达，所以本次使用固定随机种子（2412）生成的 IF2412/IF2503 结算价和开盘价，价格按 0.2 点取整，并剔除国庆休市日。Data 交付真实日线后，把 `synth()` 换成真实数据读取即可重跑；判定标准不变。

## 情景
- 2024-10-07 收盘发出信号：IF 目标名义 = 1 手 × 结算价 × 300。10-08 开盘买入 1 手 IF2412。
- 只选季月合约（`contract_months="quarterly"`），`roll_days=5`。最后交易日 2024-12-20（12 月第三个周五），往前数 5 个交易日，即 **2024-12-13** 开盘展期：平 IF2412、开 IF2503。
- 2024-12-30 收盘发出平仓信号，12-31 开盘平掉 IF2503。
- 2024 年费率：开仓和平仓都是万分之 0.23，本例没有平今仓。保证金率 12%。

## 手工步骤（逐日）
1. 开仓日：VM = (当日结算价 − 开仓价) × 300；手续费 = 开仓价 × 300 × 0.000023。
2. 持有日：VM = (今日结算价 − 昨日结算价) × 300。
3. 展期日：旧腿 VM = (展期价 − 昨日结算价) × 300；新腿 VM = (今日结算价 − 展期价) × 300；展期费用 = 旧腿平仓费 + 新腿开仓费。
4. 平仓日：VM = (平仓价 − 昨日结算价) × 300；加平仓费。
5. 现金逐日累计：现金 += VM − 手续费。保证金 = 结算价 × 300 × 12%。
