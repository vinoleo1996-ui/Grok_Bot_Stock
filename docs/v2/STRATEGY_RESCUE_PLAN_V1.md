# QuantLab 策略急救 / 整体优化方案 V1

> 2026-10-10 · 研究级 · `promotion_approved=false`  
> 触发：全样本 paper `v1_paper` CAGR −8.3% / MDD −60.7%；250 烟测无成本偏甜，不可接受。

## 0. 诊断（问题不在「用了 D1」）

| 根因 | 证据 |
|---|---|
| Alpha 过浅 | 仅 M01 动量 + EP，无质量/低波/反转/微观结构 |
| 组合实现粗糙 | 硬刷新、β 袖套与 max_etf 冲突、LW 未上 |
| 执行不真 | 短窗烟测无成本；全样本有成本后崩 |
| 标签/正交弱 | 行业中性研究级申万；无风格正交（size/value 重叠） |
| 评估不严 | 无 walk-forward 分段、无基准超额分解、无分层 IC |

D1 掩码保留：它是可交易约束，不是收益来源。

## 1. 硬规则

1. 主结论只认 **Full D1 + 成本 + 涨跌停/停牌** 的全样本（或明确子样本），禁止 250 无成本对外叙事。  
2. 一次只改一类变量（成本 / 宇宙 / 因子 / 风险），对照 A/B。  
3. 全程 `promotion_approved=false`，直到 Data 证明 PIT 门禁。  
4. 对 Leo 中文短报；数字必须带来源路径。

## 2. 分阶段（按优先级）

### P0 — 把「测量」做对（本周内）
1. **B**：强制成本（佣金 2.5bp + 最低佣金逻辑 + 滑点 5bp + 印花税）+ 涨跌停/停牌当日不可交易、收益记 0。  
2. **对照**：同代码 Full D1 vs pool250；有成本 vs 无成本。  
3. **基准**：相对 510300 / 沪深300 的超额、信息比率。  
4. **冻结报告模板**：禁止再混报短窗烟测当主结论。

验收：`output/strategy_paper_costs/` 出 summary；与 `v1_paper` 对齐口径说明。

### P1 — Alpha 工厂扩容（紧接 P0）
在研究级数据上扩因子族（每族至少 1 个可复现定义 + IC/ICIR 过程指标）：
1. 动量：短/中期、残差动量（相对行业）  
2. 反转：1–5 日、20 日  
3. 价值：EP（EITIME）、BP（若有）  
4. 质量：ROE 稳定、应计（代理）  
5. 低波 / 特质波动  
6. 流动性：换手、amihud（amount 覆盖到哪算到哪，缺口标 waive）

流程：原始 → 去极值/标准化 → **行业+市值中性** → 正交化 → 等权/ICIR 加权 integrate → walk-forward。

验收：因子卡（定义、覆盖、ICIR、相关矩阵）；组合只吃 integrate 分数。

### P2 — 组合与风险
1. 解 β 袖套 vs `max_etf`：先修实现使实现 β 贴近 0.70；**不先改 Mandate**。  
2. 换手约束落地（月单边 ≤35%），禁止「硬刷新炸换手」。  
3. Ledoit–Wolf 协方差 + 风险预算加权（对照等权）。  
4. 可恢复回撤缩放按 Mandate −28% 门。

验收：持仓/β/换手诊断表；同 Alpha 下 LW vs 等权净值对照。

### P3 — 数据晋级并行（不挡 P0–P2 研究）
Data 继续：amount 覆盖、SW 官方 PIT、财务 as-filed、除权账本。研究可继续，但晋级门禁不变。

## 3. 成功标准（研究级「可接受」门槛，非晋级）

在 Full D1 + 成本 + 2018/2020→最新 上：
- 相对 CSI300/510300 的**超额**年化与信息比显著优于现 v1（至少转正且回撤可控）  
- 分段 walk-forward 不全靠单段牛市  
- 换手与成本后净超额仍成立  
仍 `promotion_approved=false`，只作为「继续研发」门槛。
