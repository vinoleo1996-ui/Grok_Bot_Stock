## 2. 公式
- β_i = Cov(r_i, r_m)/Var(r_m)，r_m = 510300 日收益；σ_i = std(r_i)·√242。
- 预算比：σ_i/16%，β_i/0.70；单轨满足授权的最大权重 w_max = min(1, 16%/σ_i, 0.70/β_i)（其余放现金）。
- Ledoit–Wolf（2004，目标 F=μI，μ=tr(S)/p）：Σ̂ = δF + (1−δ)S，δ = min(b̄², d²)/d²，d²=‖S−F‖²_F，b̄² = (1/n²)Σ_t‖x_t x_tᵀ − S‖²_F。手写实现（box 无 sklearn）。
- 风险预算：等风险贡献（ERC），RC_i = w_i(Σ̂w)_i / wᵀΣ̂w = 1/p，迭代乘子求解。

## 4. Ledoit–Wolf 与风险预算
- 收缩强度 δ = **0.040（60万）/ 0.040（100万）**：样本量 569 ≫ 资产 4，S 已稳定，收缩很小。
- ERC 权重（100万）：capacity_adv 30.6% / earnings_event 20.4% / insider_increase 24.0% / 510300 25.1%；组合 σ 15.8%，β **0.96**（60万：31.1/20.3/24.1/24.5，σ15.4%，β0.94）。
- **ERC 满足 σ16% 但违反 β0.70**。建议 Strategy 在优化中加 β 约束：wᵀβ ≤ 0.70（以现金/低β资产补足），而非只做 vol targeting。粗算：ERC 组合缩放 0.70/0.96 ≈ 0.73 倍，余 27% 现金。

## 5. 可恢复回撤钩子（默认关闭）
规则（日频，t 收盘判定、t+1 生效，避免前视）：
1. 以**策略自身影子 NAV（无钩子）**计算 DD_t = NAV_t/max NAV − 1。
2. 阶梯：DD ≤ th1 → 暴露 0.5；DD ≤ th2 → 暴露 0；被降出部分转 510300（de-β 模式）或现金（1.5%/年）。
3. 重新武装：DD ≥ re-arm（或新高）→ 暴露恢复 1.0。
4. 成本：每单位暴露切换每腿 12bp（510300 模式双腿）。
注：此为 NAV 级叠加，未重做持仓级撮合；属于近似。

## 6. 闸门（若 Strategy 要启用）
G1 OOS（非 X2）Calmar(hook) ≥ Calmar(no-hook)+0.1；G2 MDD 改善 ≥2pp；G3 年切换 ≤4 次、成本拖累 ≤0.5%/年；G4 至少一次持续型熊市（如 2018 或 2021-02→2024-01）样本里有效；G5 持仓级重模拟（非 NAV 叠加）结果一致。**当前 X2 不过 G1/G2，故保持 default-off。**

## 7. 失效条件（whipsaw）
- 阈值过紧（−6/−10）→ 切换 13 次/2.3 年，成本 ~2%，CAGR 损失 2–3pp。
- 急跌急拉（V 形）市况：触发点≈底部，re-arm≈反弹后期。
- 替代资产与原资产高相关（510300）→ de-β 无效；真正降风险需现金/国债/IF 空头（本仓未接入，缺数据，不推断）。
- 仅在持续下行（慢熊）中预期有效，但 X2 无此样本；更长窗口的轨道 NAV 缺失，**无法验证**。
