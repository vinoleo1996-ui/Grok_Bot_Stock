2018-01→2024-05 密封窗已经看过 X-D、MA-RP，CB 也已经被 Strategy 的账本部分看过（CB_PREREG §10）。所以本组合**只按两个探索窗（2015-06→2017-12，2024-06→2026-10-09）加上 2026-11 起的前向模拟盘判定**，密封窗只跑一次，**只作描述**。
密封窗的组合运行里含有 CB1，这会进一步消耗密封窗对 CB 的独立性。CB1 单独的一次性密封运行仍然保留，结果只算弱确认。

## 2. 袖套（规则都沿用已预注册的版本，不改）
- X-D：IC 季月合约，每月末近季年化贴水 ≥5% 时名义 1.0，否则 0.5（V3_B2X_PREREG §1）。
- MA-RP：510300/511010/518880，60 日逆波动，月末再平衡（MULTIASSET_PREREG）。
- CB1（降级）：双低最低 20 只等权，每 10 个交易日调仓，20 日日均成交额 ≥1000 万，剩余期限 ≥0.5 年（CB_PREREG）。选 CB1 而不是 CB2：CB1 的收益来源（债底 + 促转股选择权）与 X-D 的 β 相关性较低，CB2 主要是正股 β，会和 X-D 重复。

## 3. 组合规则
- 袖套权重：**逆 60 日波动**（不用等风险贡献，因为三者相关性的估计在 60 日窗口里噪声太大）。每月末用三个袖套代理收益的 60 日标准差计算，w_s ∝ 1/σ_s，和为 1。代理收益：X-D = 当月 X-D 敞口 × 中证500 指数日收益；MA-RP = 无摩擦 MA-RP 收益；CB1 = 当期 CB1 篮子等权收盘价日收益。只用 t 日收盘前的数据。
- 一个账户、一次引擎运行：ETF（load_execution_panels，默认处理公司行为）+ 转债 + IC 期货腿（load_index_futures_panels，与 B2 同规则）。袖套内部的目标在各自的信号日更新，没有更新时沿用。
- 臂：
| 臂 | 杠杆 |
|---|---|
| SC-RP | L = 1，不融资 |
| SC-VT10 | L = min(10% / σ̂_组合, 2.0)，σ̂_组合 = 用上述代理收益和当月权重合成的组合收益的 60 日年化波动，月末重设。现货和转债部分走 MarginConfig(Shibor 3M + 1.00%，ACT/365，max_leverage=2.0，其余引擎默认)；IC 名义同样乘以 L（期货本身只占保证金，不另外融资） |
目标波动选 10%：要做到 12% 年化，同时最大回撤 ≤25%（权益类策略的最大回撤约为波动的 1.6–1.8 倍），10% 波动大约对应 16–18% 的回撤，留出余量；上限 2× 与 X-RPVT 相同。
- 现金按 511880 计息。初始资金 3000 万元。

## 4. 判定
X1 包含 2015 股灾，要求年化 ≥12% 不现实，所以不把 X1 年化作为硬门槛。硬条件为：**两个探索窗最大回撤都 ≤ 25%，夏普都 > MA-RP 与 X-D 中较低者，且 X2 年化 ≥ 12%**。另外前向模拟盘（2026-11 起至少 6 个月）年化 ≥ 12% 且回撤 ≤ 25%。多臂通过取 SC-RP（更简单）。报告距 12% 的差距。

## 5. 钱从哪里来
- X-D：对冲方（中性产品、雪球发行方）为做空 IC 付出的贴水 + 中证500 β。
- MA-RP：期限溢价（5 年国债）+ 股权溢价 + 黄金的避险和实际利率溢价 + 再平衡。
- CB1：债底保护 + 发行人促转股的下修和强赎选择权 + 冷门低价券的定价偏低。
- 组合：三者来源不同、相关性低，按风险加权后提升夏普；SC-VT10 再用融资把波动拉到 10%，融资成本为 Shibor 3M + 1%。
