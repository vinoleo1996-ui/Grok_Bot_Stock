## 1. 机制（钱从哪里来）
1. **国债期货**：持有季月合约并按规则展期，赚期限溢价与展期结构（研究级：无 CTD/转换因子时用结算价展期 + 风险预算近似）。  
2. **黄金 518880**：按逆波/风险预算配置，改善回撤形状，付保险费；**不用金价动量信号**。  
3. **不是**利率动量、不是股指贴水、不是 FUT-RP 式 3× 久期杠杆。

## 2. 规则（事先写死）
- 代理收益：`bd = 0.5·proxy(T)+0.5·proxy(TF)`；`au = 518880` 日收益。  
- 月末：`w ∝ 1/σ`（60 日），两腿归一；`σ̂_p` 为组合实现波动。  
- `L = min(0.14/σ̂_p, L_cap_margin, **1.5**)`；`L_cap_margin = 0.80 / (w_bd·m̄_bd + w_au)`；`m̄_bd=0.5 m_T+0.5 m_TF`，`bond_margin_source='hist'`。  
- 目标权重：`T=0.5 w_bd L`，`TF=0.5 w_bd L`，`518880=w_au L`。  
- 展期：季月；`bond_roll_rule=earlier_of`，交割月前 3 日退出，`bond_delivery_margin=True`，`roll_days=15`。  
- 现金 511880 / 2% ACT/365；初始 3000 万；滑点 1 tick。  
- **臂**：`TCarry-G`（唯一主臂）。可选描述对照 `TCarry-G-EQ`（固定 50/50 债金后再乘 L，仍 L≤1.5）——若做，事先在本条保留；**默认只跑主臂**以免多重比较。本预注册**只跑 TCarry-G**。

## 3. 判定
探索 X1/X2；密封 S 只描述（FUT-RP 家族已部分见过）。  
通过 = 两窗 MDD≤25%、夏普>0，X2 CAGR∈[12%,15%]（或≥12%）。  
若 X2&lt;12%：**结论可为合格压舱零件**，不得升 L。必报 avg/peak L、债/金贡献、与 FUT-RP L3 相关（若可得）。
