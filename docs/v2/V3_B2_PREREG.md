# V3_B2_PREREG — 股指期货贴水的对冲需求补偿（Hedging-Demand Carry）预注册

研究级，promotion_approved=false，不改 Mandate。依据：V3 文档 §3 B2、§8。日期 2026-10-11。**只有文档，没跑回测，box 上没有任何期货数据。**

## 1. 机制与预测
量化中性和雪球发行方长期做空 IC/IM 对冲，期货贴水就是他们付的对冲费。"期货多头 + 现金"可以代替现货 β，并多收这部分贴水。
- 预测 1：IC/IM 年化贴水 > IF；贴水在 2019 年之后（中性规模扩张）变深。
- 预测 2：期货多头 + 现金跑赢同名义敞口的现货指数，差额 ≈ 实现的年化贴水 − 展期成本。
- 风险：雪球集中敲入或中性产品被赎回时，贴水会急剧收窄（2024-01/02），报告必须单列这段。
- 对照：2015 年之前和 2015 年股灾期间（受限仓影响）的基差行为单独描述，不当作检验。

## 2. 第一步：描述（不是策略）
IF/IC/IM 主力和当季合约的年化基差时间序列 = −(F−S)/S × 365/剩余天数；按月展期收益分解（现货收益 / 基差收敛 / 展期价差）；与中性产品规模代理的相关性（如有）。输出写到 output/v3/b2/。

## 3. 组合规则（事先固定）
- 名义敞口 = 1.0 × 组合净值（与现货对照同敞口）；保证金占用按交易所保证金 + 期货公司加收；现金 = 净值 − 保证金，按 1.5% 年化计息（同 B1）。
- 合约：**当季合约**（流动性够、展期次数少）。在到期月第三个周五之前 5 个交易日展期到下一个当季，按结算价展期。
- 成本：单边 0.23‰（中金所手续费）+ 0.5 跳滑点；平今仓按交易所当时的平今费率（2015-09 至 2023 期间变动大，按日期表执行）。
- 份数取整到整手（IF/IH ×300，IC ×200，IM ×200），剩余部分持现金。
- 风险缓冲：保证金占用超过净值 30% 时降名义敞口到保证金 ≤ 25%（2015 年保证金调到 40% 的时期会触发，事先写定）。

## 5. 指标与判定
指标：扣成本 CAGR、夏普、最大回撤、波动、实现的年化贴水、展期成本、换手、保证金峰值、追加保证金 / 降敞口次数、相对同指数现货的年化超额（含 2024-01/02 压力段）。
通过（密封窗，每臂只跑一次）= 期货臂相对同指数现货的年化超额 > 0，且 NW t > 2；最大回撤 ≤ 同指数现货 + 3pp；两个探索窗超额符号相同。另外报告是否 ≥10%/年。B2 是"β 的替代实现"，**不单独承担 10% 目标**，通过后作为 B1 的实现方式。多臂通过时，IF 优先（容量和与 510300 的一致性）。

## 6. 评估顺序
1. 先做描述统计（全样本，基差描述不涉及策略选择，但同样不调参）。
2. 探索窗：2015-06-01→2017-12-31（2015-09 起受限仓，流动性极差，标注），2024-06-01→最新。
3. 密封窗：2018-01-01→2024-05-31，每臂一次。

## 9. Eng 请求（引擎现在不支持期货）
run_weight_schedule 是现货现金账户：没有保证金、合约乘数、逐日盯市、展期、到期交割。需要：
1. 期货品种规则：乘数、最小变动 0.2 点、整手、无印花税、中金所费率（含平今，按日期），涨跌停 ±10%（按 pre_settle）。
2. 逐日盯市：按结算价结算盈亏到现金；保证金占用 = 名义 × 保证金比例（按日期表）；保证金不足时记录事件。
3. 展期：给定"连续敞口"目标（如 {'IF': 1.0}），按规则自动平旧开新，或者支持按到期日自动交割到现金（交割结算价）。
4. 现金计息参数 cash_rate（B1 也需要）。
5. 期货与现货混合持仓（510300 + IF）在同一账户里；报告 margin_peak、variation_margin、roll_cost 分项。
在 1–3 完成并通过单合约对账（手工算一个 IF 季度的盈亏）之前，B2 和 B1-L 不跑正式数。
