## 臂 1：S1 — 消息/舆情脉冲调节 β

### 机制（独特收益来源）
在宽基或中大盘 β 袖套上，用**平台舆情脉冲**（雪球讨论热度/情绪、同花顺热股与资金关注）做**仓位调节器**，不是选股排序主线：
- 脉冲**过热**（短期情绪拥挤、讨论暴增且价格已涨）→ 主动降股票 β / 加压舱；
- 脉冲**冰点且出现政策/解禁类可核对事件共振**→ 允许把 β 从低档抬回锚位（仍受风险预算与回撤刹车约束）。

收益来自：**散户与游资过度交易造成的短期风险溢价扭曲**，以及机构被迫在情绪极端时调整敞口时留下的补偿；调节的是 β 的**时变幅度**，不是「追涨行业/动量排名」。

### 钱从谁来
1. **过度交易的一方**：情绪高潮时追高者、冰点时恐慌砍仓者，付出错误时点的冲击与反转成本。  
2. **被迫调仓的机构**：风控/赎回压力在拥挤段卖出，给有纪律的 β 调节留下流动性溢价。  
3. **不是**：行业动量赢家、也不是「新闻标题 NLP 猜涨跌」的选股 alpha（那条归 Alpha 线；本臂只调组合层 β）。

### 失效条件（可证伪）
- 情绪指标与后续 5–20 日收益在探索窗上**同号相关且稳定**：说明在「追热」而非「反拥挤」，机制反了 → 否决。  
- 去掉舆情调节、只留静态 β 锚后，X2 年化与回撤几乎不变 → 脉冲无增量 → 否决。  
- 平台改版/限流导致序列断裂，或 available_at 无法严格 PIT（用了当日盘中热度做当日收盘调仓）→ 数据不合格，停跑。  
- 调节频率高到月换手破 Mandate 上限，成本吃掉脉冲边 → 否决。

### 探索窗判定
- L≤1.5；毛敞口≤1.5；默认 β 锚 ~0.7，脉冲只在预注册写死的分位阈值内缩放（例如拥挤分位>q_hi → β×0.5；冰点+事件 → 最高回到锚，不加杠杆追涨）。  
- 两窗 MDD≤25%、夏普>0；X2 CAGR ∈ [12%, 15%]（或 ≥12% 并报距 15%）。  
- **硬对照**：同宇宙静态 β（无脉冲）、以及「脉冲符号翻转」安慰剂——翻转后若更好，则原假设失败。

### 数据堵点
- **雪球 / 同花顺历史 PIT 尚未落地**（当前事件流见 `EVENT_FLOW_DATA_STATUS.md`：公告/龙虎榜/两融有进展，舆情平台未交）。  
- 必须字段：`trade_date, source, instrument_or_market, heat, sentiment_score, available_at`；`available_at` 不得早于平台可查时刻（建议 T 日 18:00 或次日开盘前）。  
- 堵点解除前：**只写预注册与接口，不开探索**。

### 与已失败/已有臂的关系
- **≠ B1**：B1 用 ETF 份额/成交额做「政策托底」深度信号，探索已失败；S1 用平台情绪调节 β，机制不同。  
- **≠ E1 行业动量**：明确禁止用热度做行业轮动主线。  
- 可与 CIB2-EW / 压舱共存：S1 只动股票 β 袖套权重，不改转债条款规则。

## 臂 2：CB3-IC — 条款事件转债 + IC 贴水（L≤1.5）

### 机制（独特收益来源；相对 CIB2-EW 的差异）
**CIB2-EW** = 静态全规则 **CB2 低溢价篮** + IC≤0.5 + 国债/黄金压舱（等权）。收益来自低溢价股性 + 贴水 + 压舱，**已探索通过**，但是**持仓式**结构臂。

**本臂 CB3-IC** 把转债袖套换成 **CB3 风格的条款事件驱动**（见 `CB_PREREG.md` CB3）：
- 触发：董事会**下修提议**公告后，按 PIT `available_at` 次一可交易日买入；价格上限与持有期事先写死（草案沿用 CB3：价格≤115、持有约 20 日或股东大会否决即出）；强赎提示/实施按 actionable 表剔除或强制退出。  
- 可选叠加：**强赎博弈退出**（已在全规则 CB 中验证过过滤价值）——事件臂强调**时点**，不强调「常年躺在双低/低溢价篮里」。  
- 第二袖套：**IC 贴水半仓（名义≤0.5）**，吃对冲需求展期 carry。  
- 第三袖套：国债/黄金压舱，**三袖套毛敞口≤1，L≤1.5**，不加高杠杆。

独特来源：**发行人促转股动机下，下修/强赎条款路径在公告窗口被错误定价**（通过率、幅度、时间）+ **独立的 IC 贴水**；与静态溢价排序低相关，才值得单开一臂。

### 钱从谁来
1. **发行人与老股东**：下修稀释、强赎逼转，条款博弈中对短期定价的补偿给事件持有人。  
2. **对冲与期现账户**：IC 贴水来自卖压与展期结构（与 B2/B2LL 同源，但本臂不加满仓股指 β）。  
3. **不是**：双低/低溢价的长期截面拥挤（那是 CB1/CB2/CIB2）；也不是动量轮动。

### 失效条件（可证伪）
- 事件窗（公告后 1–20 日）扣成本超额 ≤ 0，或主要来自当日跳空且无法按 `available_at` 成交 → 机制不成立。  
- 与 **CIB2-EW 转债袖套日收益相关显著偏高**（例如相关>0.8）且超额几乎为 0 → 未提供低相关，应并回 CIB2，不单列。  
- 下修样本过少 / 标题误判率高（Data 已提示回售靠标题、下修含除权噪音）导致信号全是假事件 → 否决或等清洗。  
- X1 因转债池过小（2015–17）事件次数不足：预注册须事先声明「X1 仅定性、判定以 X2 + 前向」——若连 X2 事件次数也不足，停跑。

### 探索窗判定
- L≤1.5，gross≤1；IC 名义≤0.5。  
- 两窗 MDD≤25%、夏普>0；X2 CAGR ∈ [12%, 15%]（或 ≥12%）。  
- **相对 CIB2-EW**：须在报告中给出转债袖套与 CIB2 转债袖套的相关、以及「仅 CB3」「仅 IC05」「CB3+IC05+压舱」分解；若组合通过但贡献全来自 IC+压舱而事件袖套为负，则事件腿失败。

### 数据堵点
- 主表已有：`data/v2/cb/cb_events_call_put_reset_pit.parquet` / `cb_events_actionable_pit.parquet`（Data 已交）。  
- 仍须核对：下修「提议 vs 通过」字段、否决公告覆盖、除权误伤比例；`cb_rate` 若仍在拉，票息/赎回价兑付以 Eng 已支持的终止规则为准。  
- IC 日线：`data/v2/futures/raw/daily/` 已在；展期规则同 B2LL。

### 与已失败/已有臂的关系
- **区别于 CIB2-EW**：CIB2 是静态 CB2 篮；本臂是 **CB3 事件时点** + 同构贴水/压舱。  
- **区别于已失败的 CIB（CB1+IC05+压舱）**：不换回双低；双低 X1 崩过。  
- **区别于 B2LL**：B2LL 半仓仍过不了 X1 MDD；本臂用事件转债 + 压舱进一步压 β，不靠加杠杆。

## 臂 3：TCarry-G — 国债期货 carry + 黄金风险预算（非动量）

### 机制（独特收益来源）
只做两腿：**国债期货（T/TF）的期限/展期 carry** + **黄金 ETF（518880）风险预算对冲**，**不含 IF/IC 股指腿**。
- 债券腿：持有近季/当季合约，按预注册展期规则滚仓，收益来自**期限溢价 + 展期结构**（及有限的 roll yield），用波动或风险预算定权重，**不用利率动量、不用价格突破**。  
- 黄金腿：按风险预算（目标波动或逆波）配置，吸收利率急升与风险资产冲击，不是「金价动量」。  
- 杠杆：**默认 L≤1.5**（名义/NAV）；保证金占用受 `M+G≤0.80×NAV` 类约束。**明确不做 FUT-RP 式 3–6× 久期杠杆凑 12%。**

### 钱从谁来
1. **借款人 / 利率风险的对冲需求方**：支付期限溢价；期货多头赚该溢价（在曲线与展期友好时）。  
2. **需要尾部保险的账户**：买入黄金流动性与避险溢价时，TCarry-G 的黄金腿是卖方的对手方之一——本臂**付保险费换回撤形状**，主收益仍预期来自债 carry，不是赌金价单边。  
3. **不是**：利率动量、股指贴水（那是 B2）、也不是 FUT-RP 里「金 + 杠杆债」双趋势叠加。

### 失效条件（可证伪）
- **已见证伪信号（来自 FUT-RP 稳健性）**：去掉债券腿后收益大幅下降；利率上行期（如 2016-10→2017-12）回撤主要来自久期。若本臂在 L≤1.5 下 X2 仍主要靠黄金单边上涨，则「carry 主引擎」假说失败 → 否决或降级为压舱零件。  
- 展期收益在扣成本后长期为负（流动性差、近远价差不利）→ carry 不存在。  
- +100bp 瞬时冲击下 NAV 损失触发追保或破 MDD 预算 → 杠杆/久期仍过大。  
- 与 **FUT-RP L3** 日收益高相关且夏普不更高 → 未提供更干净的机制，仅作 L3 的残缺版，不单列晋级。

### 探索窗判定
- **L≤1.5**（硬）；两窗 MDD≤25%、夏普>0；X2 CAGR ∈ [12%, 15%]（或 ≥12%）。  
- 若 X2 达不到 12%：允许结论为「合格压舱/预算零件、不作独立主臂」，**不得**用抬 L 到 3 去凑——FUT-RP L3 已是 Leo 指定对照，不是本臂许可证。  
- 必报：平均/峰值杠杆、债腿与金腿贡献分解、利率上行子样本、+100bp 冲击、与 FUT-RP L3 相关。

### 数据堵点
- 国债期货日线/保证金历史/手续费：`data/v2/futures/`（bond_fut_daily、margin_hist、fee_hist 等）已交；2019 settle 缺口已补。  
- **CTD / 转换因子仍缺**：精细 deliverable carry 算不清时，预注册须声明用「结算价展期 + 修正久期假设」的研究级近似，并标 `promotion_approved=false`。  
- 黄金：518880 已有；注意分红与现金计息规则同既有多资产臂。

### 与已失败/已有臂的关系
- **相对 FUT-RP L3**：L3 是金 + 杠杆债 + 股指贴水的风险平价，稳健性已写明**强依赖黄金与利率下行**；本臂**去掉股指、压杠杆**，只检验「债 carry + 金预算」在 L≤1.5 下是否仍能进 12–15% 带。  
- **相对 MA-RP / LOWLEV**：那些把多资产揉进低杠杆仍探索未过；本臂更窄、机制更单一，便于证伪。  
- **不作利率动量对照主线**；若需对照，单独标 `role=control`。
