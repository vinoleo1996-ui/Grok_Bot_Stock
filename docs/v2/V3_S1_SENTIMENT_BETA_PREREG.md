## 1. 机制（钱从哪里来）
在宽基/中大盘 **β 袖套**上，用平台舆情脉冲做**仓位调节器**（非选股主线、非行业动量）：
- 拥挤过热 → 降股票 β / 加压舱；
- 冰点且与可核对政策/解禁类事件共振 → 允许 β 回到锚位（不加杠杆追涨）。

付钱方：过度交易者与被迫调仓机构。独特来源 = 情绪拥挤的风险溢价扭曲，**不是**教科书动量/轮动。
