# 外围消息面早期预警 V1（研究级）

**状态：** 规格已落盘；样例短报见 `output/d1/EXTERNAL_NEWS_WARN_SAMPLE_ZH.md`；采集草案见 `research/external_news_warn_v1.md`。  
**更新：** 2026-10-12（America/New_York）。  
**硬开关：** `promotion_approved=false`；**不下单**；**不改 Strategy 权重**；不触发 GP / 密封 / 晋级。

---

## 1. 目标

把**海外 / 政策 / 行业大事件**从「口头提醒」变成可复核的每日预警清单：

```
事件发现 → 来源与时点留证 → 影响方向判断
       → A股标的 / 板块映射（中大盘优先）
       → 机制一句话 + 关注窗口 + 置信度
       → 研究级交易建议（偏多/偏空/观望 + 理由 + 失效条件）
       → 当日预警短报（给人读；系统不下单）
```

V1 **做预警 + 研究级交易建议**，产出给人读、给 Alpha/Strategy 作 overlay 诊断输入；**禁止自动下单、禁止改 Strategy 主表权重**；建议不等于实盘指令。

---

## 2. 事件类型（V1 白名单）

| 代码 | 类型 | 典型例子 | 默认关注窗 |
|---|---|---|---|
| `US337_ITC` | 美国 337 / ITC 调查、排除令、临时救济 | 消费电子/代工链被列名或供应链牵连 | 立案日 T0→初裁/终裁窗；短窗 1–10 交易日冲击 |
| `EXPORT_CTRL` | 出口管制、实体清单、许可政策 | BIS Entity List、芯片/设备禁令 | 公告日 T0→落地日；短窗 1–5 日 |
| `TARIFF_SANCTION` | 关税、制裁、对等反制 | 301/232、行业加征 | 消息日→生效日 |
| `INDUSTRY_REG` | 行业监管（境内外） | 医药集采、平台监管、安全审查 | 征求意见→落地 |
| `MACRO_MAJOR` | 重大宏观 / 央行 / 地缘 | 意外加息、重大战争升级声明 | T0–T+3 为主 |

非白名单（个股传闻、自媒体解读、未经证实的「内部消息」）**不得**单独成条；最多记作 `note`，置信度强制 `low`。

## 3. 预警记录字段（单条）

| 字段 | 说明 | 必填 |
|---|---|---|
| `event_id` | 稳定 ID，如 `extwarn_20261012_us337_luxshare` | 是 |
| `event_title` | 一句话标题 | 是 |
| `event_type` | 上表代码 | 是 |
| `source_name` | 来源机构/媒体名 | 是 |
| `source_url` | 可复核链接（官方稿优先） | 是 |
| `published_at` | 来源标注发布时间（带时区） | 是 |
| `first_seen_at` | 本仓首次看到时点 | 是 |
| `available_at` | 研究可用时点（≥ first_seen；禁止前视） | 是 |
| `impact_direction` | `bearish` / `bullish` / `mixed` / `unclear` | 是 |
| `mapped_instruments` | A股代码+简称列表（中大盘优先） | 是 |
| `mapped_sectors` | 板块/产业链标签 | 建议 |
| `mechanism_one_liner` | **钱从谁来 / 为什么会动**（一句话） | 是 |
| `watch_window` | 关注窗口（交易日口径） | 是 |
| `confidence` | `high` / `med` / `low` | 是 |
| `universe_note` | 是否触及小盘；主线是否避开 | 是 |
| `research_stance` | 研究级立场：`偏多` / `偏空` / `观望`（仅建议，非订单） | 是 |
| `research_stance_reason` | 立场理由（机制 + 映射强度 + 时点） | 是 |
| `invalidation` | 失效条件（何消息/价格/时点出现则作废本建议） | 是 |
| `promotion_approved` | 恒为 `false` | 是 |
| `action` | 恒为 `warn_only`（系统不下单；人工自决） | 是 |
| `disclaimer` | 「研究级预警+建议，非实盘信号；禁止自动下单」 | 是 |

短报模板见样例文件；机器可读可后续落 `output/d1/external_news_warn_YYYYMMDD.jsonl`（V1 不强制）。

### 3.1 研究级交易建议（必填）

每张预警卡必须同时给出：

| 子项 | 取值 / 要求 |
|---|---|
| 立场 | 仅三档：`偏多` / `偏空` / `观望` |
| 理由 | 对应 `research_stance_reason`：谁会买/卖、映射是否直接列名、窗口是否仍开着 |
| 失效条件 | 对应 `invalidation`：官方澄清、初裁有利、股价已完全定价、窗口结束等可观察条件 |

立场是**给人看的研究建议**，不是 Strategy 权重指令，也不是自动交易信号。

## 4. 硬规则

1. **`promotion_approved=false`**：本管线任何产出不得改总开关，不得写入 Strategy 主表权重。  
2. **系统不下单**：无订单、无目标仓、无自动路由；`action=warn_only`。卡片可含**研究级** `research_stance`（偏多/偏空/观望），供人工参考；**禁止**脚本据此下单或改仓。  
3. **中大盘优先**：映射优先 CSI300 / 中证500 / 流通市值 Top1500 内标的；**禁小盘主线**。若事件主要冲击小盘，立场默认 `观望`，并写「观察、不进主线」。  
4. **双源或官方优先**：`confidence=high` 至少要有 1 条官方/监管原文，或 2 条独立非转载公开来源；否则 ≤`med`，且立场不得强于「弱偏多/弱偏空」表述（仍用三档枚举时优先 `观望`）。  
5. **时点诚实**：禁止把晚到新闻回写成更早的 `available_at`；历史回放只允许 `available_at ≤ decision_ts`。  
6. **建议须可证伪**：每条必须写 `invalidation`；不得写具体下单股数/金额/杠杆；不得写「保证收益 / 目标价必达」；可写波动放大与盯盘提醒。  
7. **与 GP/因子厂隔离**：本管线不跑 `gp_reopen_hardgate_*`，不改 AI 短清单 ACTIVE。

## 5. 与现有流水线的分工

| 流水线 | 覆盖 | 本 V1 关系 |
|---|---|---|
| **每日情报例程**（`quantlab/intel/`，产品化仍为桩） | 国内消息语料 reader / embedding / 辩论账本契约 | V1 预警短报是情报产品的**外围事件插件**：写入同一「给人读的日终摘要」槽位，但不依赖产品调度器已上线 |
| **A股公告拉取**（Data：`anns_d` → `announcements_classified_pit`） | 上市公司公告、问询、处罚等 **境内发行人披露** | **不替代**：337/BIS/关税等多半不在 A 股公告里；公告侧可作「公司是否已发风险提示」的二次确认 |
| **事件+资金结构**（龙虎榜/两融/北向等） | 成交结构滞后确认 | V1 只预警；后续若做事件窗研究，可与资金流对照，但仍 `promotion_approved=false` |
| **题材前向采集**（`theme_carrier_*`） | 涨停/题材承接机制 | 正交：题材是盘面结构；V1 是外围政策冲击映射 |
| **Strategy 主表**（MATPREM+黄金等） | 可交易研究臂 | V1 **只告警**；任何并表须单独预注册 + 用户授权 |

一句话：**公告管境内披露；本 V1 管境外/宏观/监管大事件对 A 股中大盘的映射预警。**

## 6. 日终节奏（建议，非强制调度）

1. **美东盘后 / 北京次日早间**：扫白名单源（见采集草案）。  
2. **A股开盘前 30–60 分钟**：产出或更新当日短报草稿。  
3. **日终**：定稿 `EXTERNAL_NEWS_WARN_YYYYMMDD_ZH.md`（有事件才写；无事件写一行 `no_material_external_warn`）。  
4. **人工**：用户或 Alpha 决定是否盯盘；**系统不自动调仓**。

V1 验收不要求 cron 已挂；允许人工/半自动生成样例。

---

## 7. 映射原则（标的 / 板块）

1. **直接列名** > 供应链一级供应商 > 同业可比（同业须标 `indirect`）。  
2. 优先用公开业务说明（年报「境外收入/大客户」、官方起诉状列名被告）支撑映射。  
3. 单条预警映射标的建议 3–8 只中大盘；超过则升维到板块标签 + 代表性龙头。  
4. 不确定方向时 `impact_direction=unclear` 或 `mixed`，不得硬猜涨跌。
