日期：2026-10-11 14:45 ET。不改 Mandate，不碰小盘。

## 0. 方法论声明（重要）
2018-01→2024-05 密封窗已经看过 B2-IC、MA-RP 和它们的组合，**本文件的所有变体都是事后设计**。判定只看：(a) 两个探索窗（2015-06→2017-12，2024-06→2026-10-09）；(b) 2026-11 起的前向模拟盘（Leo 的保留样本计划）。密封窗只跑一次，**只作描述**，不参与判定。

## 1. 臂（4 个，参数事先定死）
| 臂 | 规则 | 参数来由 |
|---|---|---|
| X-D 贴水深度开关 | 每月末算持有 IC 季月合约的年化贴水 b = (S−F)/S × 365/剩余自然日（F = 结算价，S = 中证500 收盘）。b ≥ 5% → IC 名义 1.0×NAV；b < 5% → 0.5×NAV，其余是现金（511880） | 5% ≈ 现金收益（约 2%）加上承担 β 尾部风险所需的补偿；低于它时，贴水对多头的补偿不足以覆盖 β 风险，只保留一半 β |
| X-C 合约选择 | 名义固定 1.0×NAV。每月末以及展期时，在"最近季月"和"下一个季月"两张合约里，持有年化贴水更深的那张；距离最后交易日 ≤ 5 个交易日的合约不选 | 对冲需求集中在流动性好的近季，远季贴水的年化值经常更深；直接选年化贴水更深的那张，没有其他参数 |
| X-RP 逆波动组合 | B2-IC 与 MA-RP 按 60 日逆波动加权（权重和为 1），月末再平衡 | 等风险，与 MA-RP 内部口径一致 |
| X-RPVT 目标波动 | X-RP × L，L = min(10% / σ̂_60, 2.0)，月末重设；融资成本 = Shibor 3M + 1.00%；L<1 时剩余部分按 Shibor 3M 计息；调整按 |ΔL| × 10bp 扣成本 | 10% 是 12% 目标对应的中间波动；2× 上限是因为 IC 本身已经内嵌杠杆（保证金约 12%），整体杠杆不宜过高 |
对照：B2-IC（名义 1.0×NAV）、510500、MA-RP。

## 2. 实现
- X-D：平台引擎 + FuturesLeg（与 B2 相同的规则：季月、提前 5 日展期、1 跳滑点、日期保证金和费率表，现金按 511880），调仓表给 IC 0.5 或 1.0。
- X-C：引擎只会持有最近的季月合约，不能指定合约，所以用研究脚本里的简化逐日盯市：日收益 = 名义 × 持有合约结算价变化 / NAV + 现金 × 511880 收益，换合约或展期按开仓、平仓手续费 0.23‰ 加 1 跳滑点扣，**不做整手取整**。先用同一个简化模拟按"最近季月"规则复现 B2-IC，与引擎结果对比，作为接线检查。
- X-RP / X-RPVT：用各臂引擎净值的日收益合成（组合层面再平衡不另计成本，X-RPVT 的杠杆调整按上面的规则扣成本）。降级：杠杆用融资代理，不另开期货仓。

## 3. 钱从哪里来
- X-D：同 B2，收的是对冲需求补偿；贴水浅时减少 β，目的是在补偿不足时少承担 β 风险。代价是贴水浅的阶段往往是牛市（中性需求减弱），开关可能会错过上涨。
- X-C：对冲方集中在近季，远季合约流动性差，需要额外贴水补偿流动性。选年化贴水更深的合约，就是同时收对冲补偿和流动性补偿。
- X-RP / X-RPVT：期货贴水和 β（IC）+ 期限溢价和黄金（MA-RP）。两者相关性低，组合后提升夏普，再用杠杆把波动拉到目标。

## 4. 判定（探索窗 + 前向模拟盘）
- 探索窗：两个窗口的夏普都要 > 对应对照（X-D、X-C 对 B2-IC；X-RP、X-RPVT 对 B2-IC 和 MA-RP 中较高者），且最大回撤 ≤ 25%（X-D、X-C 对 IC 类：不比 B2-IC 差）。
- 前向：2026-11 起模拟盘至少 6 个月，扣成本年化与探索窗符号一致，最大回撤 ≤ 25%。
- 同时报距 12% 的差距。

## 7. 新增臂 X-D-BRK（2026-10-11 16:45 ET 预注册，运行前写定）
- 规则：X-D（不变：每月末近季 IC 年化贴水 ≥5% 时满仓 1.0，否则 0.5，其余持 511880）**加上** V3 文档 §7 的组合净值回撤刹车：组合净值相对窗口内历史最高点回撤 ≥18% → IC 名义上限 0.5；≥22% → 上限 0.3。
- 触发：每日收盘检查，触发后下一交易日开盘按上限减仓（只降不加）。
- 恢复（V3 文档没有规定，这里自定并声明）：**只在月末检查**，回撤恢复到 门槛−5pp 以内时上调一档：22% 档在回撤 <17% 时升到 0.5 档，0.5 档在回撤 <13% 时解除。最高点不重置。
- 实际 IC 名义 = min(X-D 当月目标, 刹车上限)。
- 实现：平台引擎 + load_index_futures_panels 真实期货 + load_execution_panels（默认 corporate actions 开），配置与 B2/X-D 相同（季月、提前 5 日展期、1 跳滑点、日期保证金和费率表）。刹车依赖净值路径，所以迭代运行：找到下一个状态变化日 → 插入调仓信号 → 重跑，直到不再有新的变化。
- 判定：只看两个探索窗。夏普和 Calmar 都 ≥ X-D，且最大回撤小于 X-D（两个窗口都要满足）。另报与 B2-IC 的对比和距 12% 的差距。密封窗只作描述。
- 专项描述：2015-06→09、2018 全年、2024-01→02，报告区间收益、区间最大回撤、处于刹车状态的交易日占比。
- 钱从哪里来：同 X-D（对冲需求补偿 + β）。刹车本身不产生收益，只是用"深回撤时少承担 β"来换取更小的回撤。代价是 A 股深回撤之后常有政策托底反弹（V3 B1 的论点），刹车可能错过反弹，这正是要检验的取舍。
