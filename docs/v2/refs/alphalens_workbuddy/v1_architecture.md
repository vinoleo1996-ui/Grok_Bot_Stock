# 架构设计文档

## 1. 设计参考与融合

本系统融合四个参考项目的核心设计思想:

| 参考项目 | 借鉴的设计 | 在本系统中的实现 |
|---|---|---|
| **easy-stock** | 多源数据适配 + 统一行情模型 + 版本化快照;证据驱动研究(来源陈述/第三方观点/研究推断分离);大V复盘 | 四级数据源降级链(东财→腾讯→Tushare);团队宪法的"三方分离"原则;KOL 观点结构化时间线 |
| **TradingAgents** | 多智能体 LLM 交易框架:分析师团队 → 多空研究员辩论 → 风控团队 → 交易决策 | 9 角色多智能体流水线:5 侦察员 → 多空辩论 → 风控员 → 信息面主编 |
| **QuantMind** | FastAPI 微服务化;RSS 舆情监控(事件实体匹配 + 利好/利空情绪量化);自然语言机器人总入口 | GDELT 新闻雷达(9 类目 × 情绪打标);`/api/agent/ask` 对话入口;板块×类目矩阵 |
| **MiroFish** | 种子信息提取 → 构建预测环境 → 生成报告 | "种子信息"(宏观/政策/产业/舆情/技术五路数据)→ 结构化日报(八章节) |

## 3. 数据源降级链(核心设计)

每个数据能力都有多级来源,单源故障自动切换:

### 3.1 行情报价
```
push2(东财实时) → 腾讯 qt.gtimg.cn(GBK编码解析,A/HK/US 一次批量) → Tushare 日线(收盘构建)
```
- 缩放系数陷阱:中国 ETF 最小报价 0.001 元(3 位小数),与股票(2 位小数)不同,已按代码规则处理
- 指数映射陷阱:东财 `100.NDX` 实为纳斯达克综合;腾讯指数需 `us.DJI`/`r_hkHSI` 等专用代码

### 3.2 K线
```
push2his(东财) → 腾讯 fqkline(web.ifzq.gtimg.cn) → Tushare daily
```

### 3.3 Tushare 双通道
```
RDS 网关(datahubco):  快;15000 积分内接口;限流严格(未命中查询 429,Retry-After 可达 150s)
   → 5s 最小间隔 + 10次/分钟滑动窗口 + 429 退避重试 + 连续失败熔断 5 分钟
Promax 网关:          全能(美股/港股/新闻/涨停池);按接口路由优先
   → 1.2s 间隔 + 30次/分钟 + 熔断
路由表:按接口预设首选通道(如 us_daily→promax 优先,limit_list_d→promax 优先)
空结果转移:双通道清单内接口,首选返回 0 行时自动尝试备用通道
```

### 3.4 GDELT 限流应对
- 官方限流 1 次/5 秒 → 严格队列(5.5s 间隔)
- 限流响应是**纯文本**(HTTP 200),已识别并退避 15s 重试
- 9 类目 × 10 分钟周期,后台顺序抓取,API 读缓存

## 4. 多智能体流水线设计

### 4.1 角色与职责

| 角色 | 输入 | 输出 | 纪律 |
|---|---|---|---|
| 宏观信息员 | CPI/PPI/PMI/美债 | 数据事实 + 估值传导推断 | 只陈述事实,标注期号 |
| 政策贸易监管员 | GDELT 337/出口管制/宏观类目 | 事件→影响链条→板块 | 标注来源与紧迫度 |
| 产业信息员 | GDELT 产业类目 + 快讯 | 利多/利空产业信息 | 区分事实与传闻 |
| 舆情情绪员 | KOL 库 + 板块背离 + 涨停池 | 情绪温度 + 拥挤度 | "观点正确≠持仓正确" |
| 技术分析员 | K线(指数+板块ETF) | 趋势/均线/量价/位置 | 只验证不预测 |
| 多头/空头研究员 | 全部侦察员发现 | 证据链(条件句) | 标注来源时间,禁编造 |
| 风控员 | 全部 | 杠杆/拥挤度/事件日历/仓位原则 | 一票否决提醒权 |
| 信息面主编 | 全部 | 八章节结构化日报 | 先结论后依据 |

### 4.2 规则引擎与 LLM 双模式

- 未配置 `LLM_API_KEY`:全部综合环节由数据驱动的规则引擎完成(模板 + 真实数据 + 关键词情绪),**功能不降级**
- 配置后:主编结论、问答环节调用 LLM 增强,失败自动回退规则引擎

### 4.3 证据链构建示例(多空辩论)

```
宏观面:PPI 同比由负转正(2026-09, +5.0%)
  → 多方:[semi-materials] 工业品再通胀,材料价格弹性逻辑强化(东财PPI数据;若连续3个月回升则强化)
  → 空方:[all] 若无需求端跟进,涨价难以传导至中游(条件句)
情绪面:口罩哥仍重仓存储,散户拥挤度高
  → 空方:[semi-materials] 拥挤度极值时利好兑现即利空(KOL观点库)
  → 案例:2026-07 其杠杆账户网传从浮盈1.6亿到亏损6700万 → 风控员固定引用
```

## 5. 前端设计

- 暗色交易终端主题;**红涨绿跌(中国惯例)**
- ECharts 本地方案(`public/vendor/`),无 CDN 依赖
- 自绘迷你 Markdown 渲染器(日报/问答)
- 30s 自动刷新总览,120s 刷新雷达

## 6. 已知边界

- 数据源限流窗口期内(东财 push2/promax),系统自动降级;`/api/health` 可查通道状态
- 美国 CPI/PPI 无数值 API 直连(FRED/BLS 被墙),通过 GDELT 新闻跟踪读数与预期
- 港股 Tushare 日线偶发 `upstream_pool_exhausted`,已由东财/腾讯通道覆盖
- 本系统不做交易信号,只做信息面整理;所有输出附带免责声明
