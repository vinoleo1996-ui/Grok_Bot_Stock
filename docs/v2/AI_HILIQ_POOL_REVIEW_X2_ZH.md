## ③ 标准因子体检：HI_LIQ 与 FULLA，X2

**口径**
- 日度截面 Rank IC。信号在 t 日收盘计算；前瞻收益为 t+1…t+h 的对数累计收益。
- 池用当日 PIT 成员，截面不足 100 只的日子跳过。
- ICIR = 均值/标准差（日频，未年化）。t_naive = ICIR·√n；t_HAC 用 Newey-West，lag = h−1，与 Alpha 及 N8 修正后的 `leaf_selfcheck_v3.ic_tstat_hac` 同一函数。
- 「行业中性」= SW L1 内对因子做百分位、对收益去行业均值后再求相关。
- REV20 = −过去 20 日收益之和。
- EP 取 `data/v2/ep/ep_pit_daily_tushare.parquet` 的 ep（TTM 利润/市值）。e_available_at 晚于 trade_date 15:00 的占比为 0，PIT 无违规。

**体检结论**
1. 在 HI_LIQ 上，20 日反转的方向和量级都符合 A 股常识：IC 约 0.08–0.09，HAC t 在 3.9–6.9 之间，略强于 FULLA。**说明这个池子能正常识别标准因子，没有数据或口径上的异常**。
2. EP 在 HI_LIQ 上为正，但偏弱：5 日行业中性 HAC t 2.74，20 日不显著。在 FULLA 上 EP 约等于 0，因为小微盘里低 EP 的「壳/题材」票一直很强，抵消了价值因子。对 2024–26 的 X2 来说，这和市场风格一致。
3. 叶21 在 HI_LIQ 上 20 日 IC ≈ 0.0002，见 N8 烟测。对比之下 REV20 有 0.09，所以叶21「IC≈0」是因子本身弱，不是池子的问题。
4. 再次说明 t_naive 和 t_HAC 差距很大：20 日窗口下 t_naive 约是 t_HAC 的 3 倍。所以 N8 改成 lag = h−1 是有必要的。
