## 1. 机制与可证伪预测（摘自 §3）
国家队在宽基深跌后托底，截断了沪深300 的左尾。所以 β 应该随指数回撤加深而加大、过热时减小。
- P1：E[r_{t→t+20} | D_t] 随 |D_t| 上升；深回撤时条件下行偏度更高（左尾更薄）。
- P2：深回撤里 ETF 份额异常放大的日子，后 20 日收益为正，没有放大的明显更弱。份额缺失时用成交额 z 代替，标注"降级"。
- P3：D < −8% 时 20 日前瞻收益比无条件均值高 1.5–3pp，跌超 5% 的概率更低。

## 2. 公式（参数全部用 §3 的值，事先固定）
```
D_t    = ln P_t − ln max(P_{t−249..t})            # 510300 复权收盘
S_t    = z_250(ETF 份额 20 日变化)；降级版 = z_250(510300 成交额 20 日均值 / 250 日均值)
heat_t = z_250(两融余额 60 日变化) + z_250(份额 − 250 日均值)；降级版只用两融项
w_t    = clip(0.6 + 4·max(0, −D_t − 0.05) + 0.2·1[S_t>2 且 D_t<−0.05] − 0.15·max(0, heat_t − 1.5), 0.3, w_max)
```
周频（每周最后一个交易日出信号），|Δw| < 0.1 不调；T+1 成交。其余仓位放现金，按 1.5% 年化计息（有国债 ETF 数据前）。引擎：run_weight_schedule + ExecConfig.strategy_v1(impact_k=1.0, min_trade_value=2000)，corporate_actions 开，no_limit_codes={'sh.510300'}；另报 5bp / 10bp 单边双档成本敏感性。

## 4. 检验与安慰剂（描述统计，不是策略臂）
- P1/P3：按 D 分层（0~−3%、−3~−8%、−8~−15%、<−15%）报 20 日前瞻均值、跌超 5% 概率、偏度；用 Newey-West（lag 20）t 值；同时报独立回撤事件数。
- 安慰剂：(a) 同规则用在恒指/纳指上（**缺数据**）；(b) 打乱 S_t 日期，做 200 次；(c) 中证1000：用 512100（2016-11 起）代替指数。
- 回撤刹车优先级（§7）：组合净值回撤 18% → 权益敞口 ≤ 0.5，22% → ≤ 0.3，**刹车优先于 B1 加仓**（事先定死）。在 B1-F 上做一次叠加，作为压力测试报告（2015-06、2018 全年、2022、2024-01/02），不算独立臂。

## 10. 运行前固定的口径（2026-10-11，探索窗开跑前写定；参数不变）

- **调仓**：每周最后一个交易日出信号，与上一次**下单**的目标权重相比 |Δw| < 0.1 不调；第一天直接建仓。引擎 strategy_v1(impact_k=1.0, min_trade_value=2000)，corporate_actions 开，no_limit_codes={'sh.510300'}，初始资金 500 万。
