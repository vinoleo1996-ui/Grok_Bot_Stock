# MULTIASSET_PREREG — 股/债/金多资产预注册（研究级，promotion_approved=false）

日期：2026-10-11。不改 Mandate，不碰小盘。基准：510300。目标：扣成本年化 ≥ 10%、最大回撤 ≤ 25%。
引擎：run_weight_schedule + ExecConfig.strategy_v1(impact_k=1.0, min_trade_value=2000)，corporate_actions 开（ETF 用 adj_factor 回退，分红按复权因子计入），derive_nonstock_limits=True，no_limit_codes={'sh.510300'}，初始资金 500 万。

## 1. 资产（2015-01 起都有数据，data/v2/etf/etf_daily_adj.parquet）
510300（沪深300）、511010（国泰上证5年期国债ETF）、518880（华安黄金ETF）。

## 2. 臂（3 个，参数从常识事先定死，不搜索）
| 臂 | 规则 | 调仓 |
|---|---|---|
| MA-C 对照 | 510300 100% | 建仓后持有 |
| MA-F 固定配比 | 510300 40% / 511010 40% / 518880 20% | 每季末（3/6/9/12 月最后一个交易日）再平衡到目标 |
| MA-RP 风险平价（逆波动） | w_i ∝ 1/σ_i，σ_i = 过去 60 个交易日日收益标准差（后复权），三者和为 1，不加杠杆、无上限 | 每月最后一个交易日 |
40/40/20 的来由：股、债各占主要部分，黄金作为与两者都低相关的第三条腿占一半份额；这是常识设定，不是优化结果。

## 3. 钱从哪里来（每臂）
- MA-C：股权风险溢价（承担 A 股 β 波动的补偿）。
- MA-F：(1) 股权风险溢价 40%；(2) 期限溢价，即持有 5 年国债而非现金承担利率风险的补偿，加票息；(3) 黄金：没有现金流，收益来自人民币实际利率下行、货币贬值和危机避险需求（央行购金）；(4) 再平衡溢价，股债金负或低相关时按期"卖涨买跌"。它没有 alpha，主要靠分散把波动降下来。
- MA-RP：同样的来源，但按风险等权，债券权重会很大（国债波动约为股票的 1/5–1/8），所以收益主要来自期限溢价，股票贡献变小。不加杠杆时预期收益偏低，预注册时已经知道**大概率达不到 10%**，保留它是为了看风险调整后的表现。

## 4. 指标
扣成本 CAGR、最大回撤、夏普（rf=0）、Calmar、波动、换手、成本、平均权重、窗口、引擎。

## 5. 判定（密封窗 2018-01-01→2024-05-31，每臂一次）
通过 = 扣成本 CAGR ≥ 10%、最大回撤 ≤ 25%、夏普 > MA-C 同窗，且两个探索窗夏普都 > MA-C。多臂通过取最简单（MA-F < MA-RP）。

## 6. 评估顺序与口径
探索窗 2015-06-01→2017-12-29、2024-06-03→2026-10-09 先跑，再跑密封窗。现金计息：511880 后复权日收益（etf_daily_adj，2015 起）；缺失日按常数 2.0% ACT/365。单位：etf_daily_adj 的 vol 单位是手（100 份），amount 单位是千元（已核对 amount×1000 /(vol×100×close) ≈ 1），引擎输入 volume = vol×100 份，amount = amount×1000 元。
