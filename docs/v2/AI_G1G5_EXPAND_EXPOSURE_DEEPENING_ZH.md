## 4. 与「粘性假象」叙事是否一致？

**一致，且补上了结构证据。**

1. **归因短报**：半窗 2026YTD≈+5% vs 满窗≈−7.5%≈C0，主因密封窗末篮前推运气。  
2. **本暴露**：该末篮 = **高银行集中（45%）+ 高 HHI（0.255）+ 近零动量超额** 的防守结构；满窗真日更则持续维持 **正动量暴露** 并降低银行极端集中 → 2026 回撤段贴指数。  
3. 因此半窗 any_pass=true **不可外推**：过闸依赖不可复现的行业/风格抽签，而非稳定行业 alpha 或可迁移的低动量暴露工艺。  
4. 满窗路径 2025≈C0、2026≈C0 与「中大盘 β + 薄动量溢价」画像吻合；行业层面未见独立、稳定的超额来源。
