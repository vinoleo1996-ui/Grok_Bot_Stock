## 3. 口径差异逐项（AI 代码 research/ai_hiliq_sec8_supplement.py）
1. 风格集：AI 是 SW L1 + logmv（cs_panel）+ mom20 + vol20（各滞后 1 日），收益截尾 [−21%, +31%]；Alpha 是 SW L1 + log 流通市值 + β120 + mom(t−120→t−20) + log ADV20，带截距，不截尾。**这是 B 符号相反的唯一主因。**
2. 符号约定：两边都是「腿多头 = 正」，残差 = 实际 − 拟合，没有反号。
3. 期限/时点：AI 的 neutral_net 是日频，H = W.shift(1)，再滞后 1 日计收益（等效 2 日滞后，与 Alpha 的 W.shift(2) 一致）。AI 的 IC 期限 h=1/5/20、前瞻 t+2→t+h+1；Alpha 的 IC 是 h=20、原始 t→t+20、不滞后。HAC lag 两边都是 h−1=19。
4. 加权：腿文件 20 名**全部等权 0.04**（每日不同权重数 = 1）。所以「按权重取 top-N」是任意子集：Alpha 的 `rank(method="first")` 等于按列序（代码字母序）取前 6/10；AI 的 `leaf_topn` 是 sort_values 并列取前 N。两边的 60万/100万 子集都不代表 α 排序；20 名全袖（±7.1%）更可比。
5. **stock_share（AI neutral_net）定义**：`stock_share = mean_t Σ_{非ETF} H[t,i]`，其中 H = 腿文件 target_weight 滞后 1 日（含 20% 510300 压舱）。均值取自腿文件**全部日期**（2024-01 起，先算均值、后截 X2），值为 0.7986。AI 的净超额**不归一到 100% 股票**，是账簿口径（股票袖约 80%，ETF 残差收益记 0），换手成本按整本账簿计。Alpha 是 top-N 归一到 100% 股票。两者幅度差约为 1/0.8 倍（13.7%→17.3%）。
6. 成本：两边都是 17.5bp × 双边换手。AI 按整本账簿（含 ETF 调仓）计，Alpha 按股票袖计，差别很小。
